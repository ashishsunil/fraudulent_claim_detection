# fraudulent_claim_detection

 🛡️ Insurance Fraud Detection

A machine learning project to help **Global Insure** detect fraudulent insurance claims using historical data. This end-to-end pipeline includes data cleaning, exploratory analysis, feature engineering, model development, evaluation, and recommendations for deployment.

## 📊 Objective
To build a predictive model that flags potentially fraudulent insurance claims, reduces manual investigation workload, and helps minimize financial losses.
